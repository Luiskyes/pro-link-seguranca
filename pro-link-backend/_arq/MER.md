# Modelo Entidade-Relacionamento (MER) — CREA Pro-Link

Este MER foi gerado a partir do schema oficial `_arq/estrutura.sql`.

Arquivos de entrega:

- `MER.png` — diagrama visual em alta resolução;
- `MER.pdf` — versão pronta para impressão/apresentação;
- `MER.dot` — fonte editável do diagrama;
- `estrutura.sql` — definição completa das tabelas, chaves, índices e relacionamentos.

O modelo contém **33 tabelas** e **49 relacionamentos por chave estrangeira**. Para preservar a legibilidade, o diagrama exibe principalmente chaves primárias/estrangeiras; o detalhamento de todos os campos está em `DICIONARIO_DADOS.md` e `estrutura.sql`.
